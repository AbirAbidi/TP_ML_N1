Linear and Quadratic Regression with Gradient Descent
📌 Project Overview
This project implements Linear Regression and Quadratic Regression using Gradient Descent with Python, NumPy, and Matplotlib.

The objective is to train regression models, evaluate their performance using Mean Absolute Error (MAE), and study the effect of hyperparameters such as the learning rate (alpha) and the number of iterations.

📊 Project Tasks
The project covers the following tasks:

Q1: Implement a linear regression model and gradient descent.
Q2: Define hyperparameters: learning rates and iteration counts.
Q3: Evaluate model performance using MAE.
Q4: Visualize performance according to the learning rate.
Q5: Visualize performance according to the number of iterations.
Q6: Test additional hyperparameter values.
Q7: Analyze feature scaling and preprocessing.
Q8: Study the effect of parameter initialization.
Q9: Construct a quadratic regression model using polynomial features.
Q10: Initialize the quadratic model parameters.
Q11: Evaluate the quadratic model.
Q12: Compare linear and quadratic regression according to the learning rate.
Q13: Compare both models according to the number of iterations.
